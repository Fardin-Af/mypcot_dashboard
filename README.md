# Mypcot Dashboard

A Flutter dashboard application developed as part of a technical assignment.

## Features

- Orders dashboard
- Subscriptions dashboard
- Customers dashboard
- Swipeable dashboard cards
- Date and timeline section
- New order activity card
- Bottom navigation
- Floating action button

## Tech Stack

- Flutter
- Dart
- Android
